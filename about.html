Welcome to Uncle Nick's!!

Welcome to my Uncle Nick's Lawncare Service website! The intent and purpose behind this website are to show all the services that Uncle Nick specializes in for any lawn care need. The steps I took to create this website are an efficient home page with working links to each page. I also included information about the website, a table of all the services provided for both business and residential homes, and a contact form for customers to get in touch with Uncle Nick. There are also a few images of the different services on the home page.


I chose a clear image of a lawnmower over freshly cut grass as a background image for each page, and the color palette is green. This image helps to emphasize that this is a website for a lawn care company, and the image used brings out the colors. There is a mix of green used throughout the website. This color gives the website a grassy look. Other colors, like light blue, brown, and yellow, were previously tried, but they did not work with the green palette. Alternate colors chosen are a light-brown color and white. These two colors added with green gave the website a very earthy look and feel. The font characters are all sans-serif font. I found sans-serif to be easier to read than other font characters. I also chose a bold font-weight to make the characters stand out more and easier for customers to see. To make my site more professional and user-friendly, I used a standard website with a simple layout and navigation menu throughout. The images used are easy to see and understand, along with colors that are non-blinding and appealing to the eye.


In the future, I hope to add more images set in a slideshow, or perhaps images that present some details when clicked or hovered over. I would also like to create the storage for the image sent through the forms. Also, in the future, I would like to add some icons and social media content to the website.
